# ホスト側の設定ファイル

このフォルダにファイルを配置して、ページを再読み込みする。

| ファイル | 用途 |
| --- | --- |
| `icon.png` | Oisiicord のアイコン。PNG、10 MiB 以下、縦横 8192 px 以下 |
| `dm.mp3` | 「ダイレクトメッセージ」を5回押したときの音声。MP3、20 MiB 以下 |

どちらも省略できる。`icon.png` がない場合は標準アイコンを使う。ファイルのシンボリックリンクは使用できない。

更新処理はこのフォルダのカスタムファイルを上書きしない。アプリのフォルダ全体を手動で移動・削除する場合は、このフォルダも残す。
