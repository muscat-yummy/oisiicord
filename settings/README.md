# ホスト側の設定ファイル

このフォルダにファイルを配置して、ページを再読み込みする。

| ファイル | 用途 |
| --- | --- |
| `beta.json` | 登録用の招待コード。初回起動時に作成 |
| `icon.png` | Oisiicord のアイコン。PNG、10 MiB 以下、縦横 8192 px 以下 |
| `changelog.md` | ホームの更新ログ。UTF-8、128 KiB 以下 |
| `dm.mp3` | 「ダイレクトメッセージ」を5回押したときの音声。MP3、20 MiB 以下 |

すべて省略できる。`icon.png` がない場合は標準アイコンを使う。ファイルのシンボリックリンクは使用できない。

更新処理はこのフォルダのカスタムファイルを上書きしない。アプリのフォルダ全体を手動で移動・削除する場合は、このフォルダも残す。

## 更新ログ

`changelog.md` を作り、表示したい内容を書く。ファイルがない場合や空の場合、ホームの更新ログ欄は表示しない。固定の更新ログはない。

書式は次のとおり。日付は省略できる。上から順に表示する。

```markdown
## 2026-10-25 更新タイトル

ここに本文を書く。

- 変更点
- 変更点

## 前の更新タイトル

本文
```

見出し、段落、箇条書きに対応する。HTMLはテキストとして表示する。保存後にページを再読み込みするか、アプリのタブに戻ると反映される。サーバーの再起動は不要。`bun run update` でこのファイルを上書きしない。

## ベータ登録

`beta.json` は起動時に存在しなければ次の内容で作成する。

```json
{
  "beta_mode": false,
  "code": ""
}
```

`beta_mode` が `true` で、`code` が空文字でない場合だけ、新規登録に同じ招待コードを要求する。コードは大文字・小文字・空白も含めて一致させる。既存アカウントのログインとサーバー参加用の招待リンクは影響を受けない。

保存後の登録要求から反映する。再起動は不要。UTF-8（BOMあり・なし）とBOM付きUTF-16 LE/BEを読み込める。形式が不正な場合は登録を停止し、ログインは継続できる。エラーにはJSON形式・項目の型・読み取り権限などの理由を表示するが、招待コードの値は表示しない。コードは公開APIに返さない。このファイルはGit管理の対象外で、`bun run update` でも上書きしない。

## LTC決済

`store.json` は初回起動時に次の内容で作成する。設定するまで販売は無効。

```json
{
  "enabled": false,
  "btcpay_url": "",
  "store_id": "",
  "api_key": "",
  "plus_ltc": "",
  "boost_ltc": "",
  "boost_days": 30
}
```

Litecoinを有効にしたBTCPay Serverの公開HTTPS URL、ストアID、APIキーを設定する。APIキーは対象ストアの請求書作成・閲覧に限定する。ウォレットの秘密鍵はOisiicordに設定しない。`plus_ltc` と `boost_ltc` はLTC単位の文字列で、小数点以下8桁まで。価格を設定して `enabled` を `true` にすると購入できる。保存後の要求から反映し、再起動は不要。

標準の添付上限は1ファイル1024MiB。Plusは買い切りで1ファイル2048MiBまで添付でき、参加サーバー上限100、参加中のサーバーのカスタム絵文字をDMや別の参加サーバーでも使える。ブーストは購入ごとに `boost_days` 日間を加算し、期間中は絵文字・チャンネル・メンバーの上限を各300にする。ボイス通話の接続人数は増やさない。期限切れで既存のメンバー・チャンネル・絵文字は削除しない。通常上限を超えている場合、新しい追加を止める。

請求書は `LTC-CHAIN` に限定し、BTCPayの `Settled` とLTCの入金額・残額を確認した後に反映する。ブラウザからの「支払い済み」という申告は使わない。請求書ID・注文・通貨・金額を照合し、同じ請求書を二重反映しない。購入画面を開いている間は20秒ごとに確認する。購入履歴の「入金を確認」でも再確認できる。LTC以外や未確認・不足入金では反映しない。

`store.json` は外部配信せず、Gitと更新の管理対象から外す。新しい販売設定へ切り替える前に、未処理の請求書を確認する。BTCPayの接続先・ストアを変更すると、以前の請求書は旧設定へ戻すまで照会できない。

- [請求書作成の公式例](https://docs.btcpayserver.org/Developers/api/examples/)
