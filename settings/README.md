# ホスト側の設定ファイル

このフォルダにファイルを配置して、ページを再読み込みする。

| ファイル | 用途 |
| --- | --- |
| `icon.png` | Oisiicord のアイコン。PNG、10 MiB 以下、縦横 8192 px 以下 |
| `changelog.md` | ホームの更新ログ。UTF-8、128 KiB 以下 |
| `dm.mp3` | 「ダイレクトメッセージ」を5回押したときの音声。MP3、20 MiB 以下 |

すべて省略できる。`icon.png` がない場合は標準アイコンを使う。ファイルのシンボリックリンクは使用できない。

更新処理はこのフォルダのカスタムファイルを上書きしない。アプリのフォルダ全体を手動で移動・削除する場合は、このフォルダも残す。

## 更新ログ

`changelog.md` を作り、表示したい内容を書く。ファイルがない場合や空の場合、ホームの更新ログ欄は表示しない。固定の更新ログはない。

書式は次のとおり。日付は省略できる。上から順に表示する。

```markdown
## 2026-10-25 更新タイトル

ここに本文を書く。

- 変更点
- 変更点

## 前の更新タイトル

本文
```

見出し、段落、箇条書きに対応する。HTMLはテキストとして表示する。保存後にページを再読み込みするか、アプリのタブに戻ると反映される。サーバーの再起動は不要。`bun run update` でこのファイルを上書きしない。
