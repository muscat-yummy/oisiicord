# 自主退出・ブロック・アカウント削除・本番添付 — 2026-10-25

4項目を実装・確認した。本番添付はend2end.techへの実接続による確認で、公開サーバーへのアプリ全体のデプロイを意味しない。

| 項目 | 追加した操作と動作 |
| --- | --- |
| 自主退出 | サーバーメニュー、右クリック、サーバー設定から退出。所有者がオフラインでも可能。退出者への新規鍵配送とHTTPアクセスを止める。既存の招待は無効になり、新しい招待からは再参加できる |
| ブロック | プロフィールから設定し、ユーザー設定の一覧から解除。双方のDM送信・DM通話をサーバーでも拒否。共通サーバーのメッセージは折りたたみ、通知と入力中表示を抑止。共通通話の直接接続も避ける |
| アカウント削除 | ユーザー名、現在のパスワード、所有サーバーの削除同意で確認。全セッションを失効し、プロフィール・vault・認証情報・所属・ブロック設定を削除。所有サーバーも削除する |
| 本番添付API | 接続先固定、サイズ上限、タイムアウト、リダイレクト拒否、JSONの成功確認を専用アダプターに整理。HTTP 200でも削除エラーの応答は失敗として扱う |

送信済みメッセージ・添付、受信者のコピー、既存バックアップはアカウント削除による遠隔消去の対象ではない。過去の署名を壊さないため、IDと公開鍵を匿名の記録として残す。所有者の自主退出には、先にサーバー削除が必要。所有権譲渡は今回の実装範囲に含めない。

## 検証

| 確認 | 結果 |
| --- | --- |
| 署名偽造・所有者の退出 | 拒否 |
| 退出後の履歴アクセスと新規受信鍵 | 拒否・配送対象から除外 |
| 退出後の古い招待、古い参加証明の再送 | 拒否 |
| 一度見た退出証明を、より大きい未署名バージョンで消す巻き戻し | ブラウザの退出記録で拒否 |
| 新しい招待での再参加と過去ログ | 通過 |
| ブロック後のDM送信、相手側だけの解除での回避 | 拒否 |
| ブロック中の共通会話・通知・入力中表示 | 本文の折りたたみと通知抑止を確認 |
| 間違ったパスワード、所有サーバーの省略 | 削除を拒否し、データを保持 |
| アカウント削除と2タブ | 両タブのログアウト、保存キー・本人用メモ・設定の除去を確認 |
| 削除したユーザーの過去の会話 | 匿名表示で復号・署名検証を継続 |
| DB更新 | スキーマ3。更新前のバックアップ、旧データ保持、失敗時の復旧と参照整合性を確認 |
| end2end.tech本番 | テスト用の128バイトを暗号化した1ファイルでアップロード・取得・復号・削除がすべて成功 |

変更に関係する自動検証31件とブラウザの操作確認が通過。新規9画面をスクリーンショットから目視した。画像は作業環境に保持し、GitHubには公開していない。画面名は [lifecycle-manifest.json](lifecycle-manifest.json) に記録した。

通常の自動テストは本番サービスに送信しない。本番APIへの確認は今回1件だけ行い、削除まで完了した。ファイルID・削除パスワード・セッション・秘密鍵はログに出していない。大容量、長期保存、障害時の可用性、別端末からの実機通話をこの結果で保証しない。

## コマンド

- `bun run test:lifecycle`：一時DBでブラウザ操作を再現する。
- `bun test tests/lifecycle.test.ts tests/file-adapter.test.ts`：署名・権限・削除・添付応答をローカルで確認する。
- `bun run test:files:live`：実行した場合だけ、本番へ小さなテスト用暗号文を1件送信・取得・削除する。

一般公開の安定版としての判定は引き続き保留。実機・別ネットワークでの通話、所有権譲渡、通報運用、チャンネル権限、独立したセキュリティレビューなどは [確認一覧](README.md) に残している。
