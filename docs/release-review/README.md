# リリース確認 — 2026-10-25

判定：ローカル検証を通過した招待制βの候補。一般公開の安定版としては保留。

一時DBと使い捨てアカウントで実際にブラウザを操作し、62枚の画面をスクリーンショットから目視確認した。コードを読んだだけの判定ではない。画面一覧は14枚の画像にまとめた。画像は作業環境に保持し、このGitHub差分には含めない。実ユーザーの会話・アカウント・本番DBは使用していない。GitHub Releaseや公開サービスへのデプロイは行っていない。

## 検証環境・再現方法

Bun 1.4.4、Chromium 153、Linux、一時SQLite DB、1440×960と390×844の表示幅を使用。自動テストは既存56件と絵文字1件の計57件が通過し、通話の修正後は変更したWebSocket検証だけを再実行した。型確認も通過。成功した機能の全体テストを繰り返さず、停止した部分と未確認部分に絞って継続した。日本語フォントがない検証環境の画像は採用せず、表示用フォントを用意して画面だけを撮り直した。

今回使用したブラウザ検証は `test:interface`、`test:workspace`、`test:community`、`test:history`、`test:login`、`test:developer`、`test:productivity` と、新設した `test:release`。通常は `bunx playwright install chromium` でブラウザを用意する。音楽テストのファイル生成にはFFmpegを使用する。

`bun run test:release` は設定20画面、絵文字の倍率、通信切断・復帰、履歴の再試行と継続読み込みを確認し、`docs/release-review/screenshots` に画像を出力する。他のブラウザ検証は通常の `docs/screenshots` に出力する。この報告の画面一覧には今回の確認時に取得した画像をまとめた。

外部APIの仕様は [end2end.tech公式API資料](https://api.end2end.tech/) を確認した。仕様の閲覧と、本番の通し動作確認は区別している。
